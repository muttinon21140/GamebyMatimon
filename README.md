# Hearts of Siam

เกมจำลองการบริหารประเทศแบบอินเตอร์แอคทีฟที่ให้ผู้เล่นรับบทนายกรัฐมนตรีและดูแลประเทศไทยผ่านระบบแผนที่ 77 จังหวัด

## คุณสมบัติหลัก

- แผนที่จังหวัดทั่วไทยแบบโต้ตอบได้
- ระบบนโยบายและเหตุการณ์ที่มีผลต่อความนิยม ความสุข โครงสร้างพื้นฐาน และสิ่งแวดล้อม
- ระบบหนี้สาธารณะและการจ่ายคืนหนี้
- ระบบเสียงสะท้อนจากประชาชนในรูปแบบแชท
- เมนูบันทึก/โหลดเกมและระบบออโต้เซฟ
- เกียรติยศและความสำเร็จต่าง ๆ
- ระบบระดับความยาก easy / normal / hard
- แนะนำการเล่นผ่าน tutorial

## โครงสร้างโปรเจกต์

- index.html: หน้าเว็บหลัก
- css/style.css: ไฟล์สไตล์ทั้งหมด
- js/data.js: ข้อมูลจังหวัด นโยบาย และค่าคงที่เกม
- js/game.js: กลไกเกมและระบบหลัก
- js/ui.js: UI และการแสดงผลบนหน้าเว็บ

## วิธีเล่น

1. เปิดไฟล์ index.html ในเบราว์เซอร์
2. เลือกระดับความยากและเริ่มเกม
3. คลิกที่จังหวัดบนแผนที่เพื่อดูสถานการณ์และอนุมัตินโยบาย
4. ควบคุมงบประมาณ ความนิยม และเสถียรภาพของรัฐบาลให้คงอยู่ได้ยาวนาน

## เทคโนโลยีที่ใช้

- HTML5
- CSS3
- JavaScript
- Leaflet.js สำหรับแผนที่

## หมายเหตุ

โปรเจกต์นี้ออกแบบมาเพื่อให้ผู้เล่นได้ลองรับรู้ถึงความท้าทายของการบริหารประเทศในระดับพื้นที่และระดับชาติในรูปแบบเกมที่เข้าใจง่าย
